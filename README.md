# Python实现机票数据分析与可视化

## 核心功能
- 数据清洗：处理缺失值、空值、异常值
- 数据预处理：标准化处理
- 数据统计
- 数据可视化：航班数量随时间变化趋势、机票价格均值对比、机场数量和航司分布、客机型偏好、航班数量与日期、机票价格分布、价格分布范围和统计数据
- 研究结论

## 适用场景
- 机票行业市场分析
- 航班数据深度挖掘
- 消费者偏好研究
- 竞争对手分析
- 决策制定支持

## 技术特点
- 使用pyecharts进行数据可视化
- 使用pandas进行数据处理和统计
- 使用numpy进行数据预处理
- 系统稳定运行，测试无bug
